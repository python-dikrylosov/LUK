# MTZ_UFA_SHOP - Полноценный интернет-магазин запчастей

## 🚜 Описание проекта

Профессиональная система управления магазином запчастей для тракторов МТЗ, ЯМЗ, КАМАЗ, Т-150 с:
- 🛒 Полноценным каталогом товаров и корзиной
- 📦 Управлением складскими остатками
- 👤 Личными кабинетами покупателей и продавцов
- 📊 Интерактивными схемами тракторов
- 📱 Заказом деталей через Telegram
- 🔐 Ролевой моделью (покупатель, продавец, администратор)

## 🚀 Установка на Windows 10

### Шаг 1: Подготовка окружения

```powershell
# Создать директорию проекта
mkdir C:\mtz_ufa_shop
cd C:\mtz_ufa_shop

# Создать виртуальное окружение
python -m venv venv

# Активировать виртуальное окружение
venv\Scripts\activate
```

### Шаг 2: Установка зависимостей

```powershell
pip install python-telegram-bot==20.7
pip install sqlalchemy==2.0.23
pip install aiosqlite==0.19.0
pip install openpyxl==3.1.2
pip install pandas==2.1.4
pip install pillow==10.1.0
pip install python-dotenv==1.0.0
pip install aiofiles==23.2.1
```

Или одной командой:
```powershell
pip install -r requirements.txt
```

### Шаг 3: Настройка переменных окружения

Создайте файл `.env` в корне проекта:

```env
# Токен бота от @BotFather
BOT_TOKEN=ваш_токен_бота

# Администраторы (ID Telegram через запятую)
ADMIN_IDS=123456789,987654321

# Путь к базе данных
DATABASE_PATH=C:/mtz_ufa_shop/data/shop.db

# Директории
IMAGES_DIR=C:/mtz_ufa_shop/data/images
EXPORTS_DIR=C:/mtz_ufa_shop/data/exports
LOGS_DIR=C:/mtz_ufa_shop/logs

# Валюта
CURRENCY_SYMBOL=₽
```

### Шаг 4: Инициализация базы данных

```powershell
python database/init_db.py
```

### Шаг 5: Запуск бота

```powershell
python bot.py
```

## 👥 Ролевая модель

### Покупатель 🛒
- Просмотр каталога товаров
- Поиск запчастей по названию/артикулу
- Добавление товаров в корзину
- Оформление заказов
- Отслеживание статуса заказа
- Личный кабинет с историей покупок
- Просмотр схем тракторов

### Продавец 🏪
- Управление товарами (добавление/редактирование)
- Управление складскими остатками
- Обработка заказов
- Просмотр статистики продаж
- Выгрузка отчетов

### Администратор ⚙️
- Управление пользователями
- Назначение ролей
- Полный доступ к статистике
- Настройки системы
- Управление категориями товаров

## 📋 Основные команды бота

### Для всех пользователей:
- `/start` - Приветствие и главное меню
- `/catalog` - Каталог товаров
- `/search` - Поиск запчастей
- `/cart` - Корзина
- `/profile` - Личный кабинет
- `/schematic` - Схемы тракторов
- `/help` - Помощь

### Для продавцов:
- `/seller_panel` - Панель продавца
- `/add_product` - Добавить товар
- `/stock_manage` - Управление складом
- `/orders_process` - Обработка заказов

### Для администраторов:
- `/admin_panel` - Панель администратора
- `/users_manage` - Управление пользователями
- `/statistics` - Статистика магазина
- `/export_data` - Выгрузка данных

## 🗄️ Модель данных

### Таблица Users
```sql
- id (INTEGER PRIMARY KEY)
- telegram_id (INTEGER UNIQUE)
- username (TEXT)
- full_name (TEXT)
- phone (TEXT)
- role (TEXT: buyer/seller/admin)
- created_at (DATETIME)
- balance (REAL)
```

### Таблица Products
```sql
- id (INTEGER PRIMARY KEY)
- article (TEXT UNIQUE)
- name (TEXT)
- description (TEXT)
- category (TEXT)
- tractor_model (TEXT: MTZ/YMZ/KAMAZ/T150)
- price (REAL)
- stock_quantity (INTEGER)
- min_stock_level (INTEGER)
- image_path (TEXT)
- created_at (DATETIME)
- updated_at (DATETIME)
```

### Таблица Orders
```sql
- id (INTEGER PRIMARY KEY)
- user_id (INTEGER FOREIGN KEY)
- status (TEXT: new/confirmed/paid/shipped/delivered/cancelled)
- total_amount (REAL)
- created_at (DATETIME)
- updated_at (DATETIME)
- delivery_address (TEXT)
- comment (TEXT)
```

### Таблица OrderItems
```sql
- id (INTEGER PRIMARY KEY)
- order_id (INTEGER FOREIGN KEY)
- product_id (INTEGER FOREIGN KEY)
- quantity (INTEGER)
- price_at_purchase (REAL)
```

## 🖼️ Схемы тракторов

Система поддерживает интерактивные схемы для:
- **МТЗ-80/82** - основная модель
- **МТЗ-1221** 
- **ЯМЗ-236/238** - двигатели
- **КАМАЗ** - грузовики
- **Т-150** - гусеничный трактор

При выборе схемы пользователь может:
1. Просмотреть общее изображение
2. Кликнуть на узел для детализации
3. Увидеть список запчастей узла
4. Сразу добавить запчасти в корзину
