## 📊 Обзор проекта

Этот Telegram-бот представляет собой полноценный интернет-магазин запчастей для сельскохозяйственной техники. Бот позволяет пользователям просматривать каталог товаров, добавлять их в корзину, оформлять заказы и получать информацию о своей истории покупок.

### 🔑 Ключевые особенности
- 📱 Удобный интерфейс с инлайн-кнопками и меню
- 🔍 Мощная система поиска по названию и каталожному номеру
- 📦 Управление корзиной с возможностью оформления заказа
- 📊 Ежедневные отчеты в группу с аналитикой продаж
- 📞 Сохранение контактной информации пользователей
- 📈 Хранение истории заказов для каждого пользователя

### Подробная схема взаимодействия

```
1. СТАРТ БОТА
   Пользователь → /start → Приветствие + Главное меню
   
2. ПРОСМОТР КАТАЛОГА
   Пользователь → Каталог → Категории → Товары → Карточка товара
   
3. ПОИСК ТОВАРА
   Пользователь → Поиск → Ввод запроса → Результаты поиска
   
4. ДОБАВЛЕНИЕ В КОЗИРНУ
   Товар → "Добавить в корзину" → Обновление carts.json
   
5. ОФОРМЛЕНИЕ ЗАКАЗА
   Корзина → "Оформить заказ" → Ввод контактов → Сохранение заказа
   
6. ОТЧЁТЫ
   Ежедневно → Аналитика → Отправка в админ-группу
```

## 🚀 Установка и запуск на Windows 10

### Шаг 1: Установка Python

1. Скачайте Python с официального сайта: https://www.python.org/downloads/
2. Запустите установщик
3. ✅ **Обязательно отметьте галочку** "Add Python to PATH"
4. Нажмите "Install Now"

### Шаг 2: Проверка установки

Откройте Командную строку (cmd) или PowerShell и выполните:
```bash
python --version
pip --version
```

### Шаг 3: Создание рабочей директории

```bash
mkdir C:\mtz_ufa_bot
cd C:\mtz_ufa_bot
```

### Шаг 4: Создание виртуального окружения

```bash
python -m venv venv
venv\Scripts\activate
```

### Шаг 5: Установка зависимостей

Создайте файл `requirements.txt` со следующим содержимым:
```
python-telegram-bot==20.7
openpyxl==3.1.2
pandas==2.1.4
aiofiles==23.2.1
```

Установите зависимости:
```bash
pip install -r requirements.txt
```

### Шаг 6: Получение токена Telegram Bot

1. Откройте Telegram и найдите @BotFather
2. Отправьте команду `/newbot`
3. Придумайте имя для бота (например: MTZ_UFA_Bot)
4. Придумайте username для бота (должен заканчиваться на _bot, например: mtz_ufa_shop_bot)
5. Скопируйте полученный токен (выглядит как: `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`)

### Шаг 7: Настройка конфигурации

Создайте файл `config.py`:
```python
# Токен вашего бота от BotFather
BOT_TOKEN = "ВАШ_ТОКЕН_ЗДЕСЬ"

# ID админ-группы для отправки отчётов (опционально)
ADMIN_GROUP_ID = -1001234567890

# Путь к базе данных товаров
PRODUCTS_FILE = "data/products.xlsx"

# Пути к файлам данных
USERS_FILE = "data/users.json"
CARTS_FILE = "data/carts.json"

# Папка с изображениями
IMAGES_FOLDER = "data/product_images"

# Лог-файл
LOG_FILE = "logs/bot.log"
```

### Шаг 8: Создание структуры папок

```bash
mkdir data
mkdir data\product_images
mkdir logs
```

### Шаг 9: Подготовка базы данных товаров

Создайте Excel-файл `data/products.xlsx` со следующими колонками:
- `id` — уникальный идентификатор товара
- `name` — название товара
- `article` — артикул/каталожный номер
- `price` — цена
- `category` — категория
- `description` — описание
- `image` — имя файла изображения (опционально)

### Шаг 10: Запуск бота

```bash
python bot.py
```

## 🔧 Конфигурация

### Переменные окружения (рекомендуется для безопасности)

Создайте файл `.env`:
```
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
ADMIN_GROUP_ID=-1001234567890
```

В `config.py` используйте:
```python
import os
from dotenv import load_dotenv

load_dotenv()
BOT_TOKEN = os.getenv("BOT_TOKEN")
ADMIN_GROUP_ID = int(os.getenv("ADMIN_GROUP_ID", 0))
```

Добавьте в `requirements.txt`:
```
python-dotenv==1.0.0
```
